## Executando localmente

### Pré-requisitos

- [Node.js](https://nodejs.org/)
- npm
- Git

### Instalação

```bash
git clone https://github.com/koyama8/Portfolio-Website.git
cd Portfolio-Website
npm install
npm run dev
```

O endereço local será exibido pelo Vite no terminal.

### Build de produção

```bash
npm run build
```

### Visualização do build

```bash
npm run preview
```

## Responsividade

A interface foi preparada para diferentes tamanhos de tela:

- Celulares compactos e modernos.
- Tablets em orientação vertical e horizontal.
- Notebooks com diferentes resoluções.
- Desktops Full HD.
- Monitores maiores e ultrawide.
- Dispositivos touch sem dependência exclusiva de hover.

Menus, cards, textos, imagens, botões e áreas de conteúdo são reorganizados conforme o espaço disponível.
